# ADR-014: 退役未实现引擎字段（riskFreeRate / withReplacement）

| 状态 | 已接受 | 日期 | 2026-08-13 | 合并 | — | 关联 | ADR-012, ADR-013 |

## Context

全仓库收敛审计发现两个"前端接受、引擎未实现"的契约字段，属于纯死配置面——保留只会误导使用者（以为可控制某项行为，实际引擎完全忽略）：

1. **riskFreeRate**：`/api/engine/efficient-frontier` 与 `/api/engine/optimize` 请求体由 `schemas/backtest.ts` 接受并透传，但 Go 引擎全仓库零匹配（`rg riskFreeRate` 在 engine-go 无结果），Sharpe 计算硬编码 `engineutil.RiskFreeRate = 0.02`。前端对两接口零传值 → 该字段既无消费者、又无真实效果。
2. **withReplacement**：`monteCarloSchema.mcParams` 接受并由前端 monte-carlo 页传 `true`，但 Go 引擎零匹配——block bootstrap 采样本身即带放回，无"不放回"实现路径。前端开关无真实语义。

## Decision

- 从请求契约删除 `riskFreeRate`（optimizeSchema / efficientFrontierSchema）与 `withReplacement`（monteCarloSchema.mcParams）；前端移除对应 UI 开关（monte-carlo 参数面板）与请求字段。
- Go 引擎不改动：`RiskFreeRate = 0.02` 常量与 MC 隐式放回抽样保持现状。
- 删除门禁按决策原则执行：确认零生产消费者、无悬挂配置面；配套测试同步迁移（optimizer-application-service.test.ts、backtest.test.ts）；本 ADR 独立提交。

## Consequences

- (+) 消除误导性配置面与前后端契约漂移；API 契约只保留引擎真实实现的能力。
- (-) 未来如需"无放回抽样"或"可配置无风险利率"，需重新引入契约并先在引擎实现（以本 ADR 为基线，成本显式可见）。
