# ADR-011: 后端代码组织（包合并 + 逻辑模块化策略）

| 状态 | 已接受 | 日期 | 2026-07-26 | 合并 | DADR-042 | 关联 | ADR-003, ADR-004 |

## Context

api/ 与 packages/backend/src/ 曾存在 30+ 对重复文件，Bug 修复需同步两处。合并后需明确逻辑边界和微服务化触发条件。

## Decision

### 1. 代码库合并（已实施）

api/ 138 文件迁移到 packages/backend/src/，导入路径重写为 @backtest/shared，api/ 已删除，2743 项测试通过。

### 2. 逻辑边界（6 模块）

auth / backtest / billing（含 Stripe webhook，挂载于 app.ts）/ data / org / admin，各模块路由 + application + queues 内聚。

### 3. 通信与拆分

- 当前：同进程函数调用；拆分后：HTTP + BullMQ
- 拆分触发：部署频率差异 / 资源竞争 / 团队 > 10 人 / 扩缩容策略差异

### 4. 依赖方向强制

dependency-cruiser 检测非法依赖与循环依赖（本地脚本 `pnpm depcheck:layer`）；CI 强制死代码检查由 knip（deadcode job）承担。

## Consequences

- (+) 消除 30+ 对重复文件；量化拆分触发条件使决策有据可依
- (-) 模块边界靠约定 + dependency-cruiser 维持
