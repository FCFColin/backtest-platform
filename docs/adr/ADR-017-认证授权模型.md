# ADR-017: 认证授权模型（JWT + RBAC + 任务所有权 + 按组织 API 密钥）

| 状态 | 已接受 | 日期 | 2026-06-24 | 合并 | 原 ADR-019/026/033 |

## Context

静态 API Key 泄露后无法撤销、无法区分用户。异步任务端点曾允许匿名访问，攻击者可遍历 jobId 读取他人结果（IDOR）。单一 ADMIN_API_KEY 无法按组织区分/吊销/审计。

## Decision

### 1. JWT + RBAC

- JWT（jose, RS256），保留 x-api-key 兼容；RBAC 三角色（ADMIN/ANALYST/READONLY）× 七权限
- Access Token 15min + Refresh Token 7d + 轮换，Redis 存储；Idempotency-Key 中间件

### 2. 异步任务所有权

- 入队写 owner（userId），查询强制认证 + 所有权校验，无权返回 404（防枚举）

### 3. 开发环境旁路

- 仅 NODE_ENV=development + DEV_SKIP_AUTH=true，固定 readonly 角色

### 4. 按组织 API 密钥

- api_keys 表存 SHA-256 哈希 + 前缀，明文仅创建时返回一次；可吊销/审计
- ADMIN_API_KEY 仅作平台 break-glass 密钥（不可吊销，须严格保管）
- /api/v1/keys CRUD（jwtAuth + resolveTenant + ADMIN_ACCESS）

## Consequences

- (+) 消除 IDOR；密钥可按组织自助管理，泄露爆炸半径收敛到单组织
- (-) Redis 成为认证依赖（Sentinel HA，故障时 503）
- (-) 按组织密钥校验需一次 DB 查询（已建唯一索引）
