# ADR-003: 语言精简（4 语言 → Go + TypeScript/React）

| 状态 | 已接受 | 日期 | 2026-06-23 | 取代 | DADR-001 |

## Context

四语言架构（Rust+Node+Go+Python）负面后果显著：Rust 编译慢（5-10min）、门槛高、生态弱；Python 子进程开销（200ms/次）、双运行时、类型不安全。Go 已有 baostock 纯 Go 替代。

## Decision

精简为 2 语言：Go（后端服务）+ TypeScript/React（前端 + API 网关）。

- Rust 引擎 → Go 引擎（gonum/mat + stat + optimize）
- Python 脚本 → Go data-fetcher（REST API 替代 akshare/yfinance SDK）
- Go 性能约为 Rust 70-90%，回测秒级延迟可接受
- 迁移：Phase 1 Go 并行 → Phase 2 Python 迁移 → Phase 3 Rust 下线 → Phase 4 CI 简化

## Consequences

- (+) 运维复杂度降 50%，CI 时间减 60%，镜像减 500MB，团队门槛降低
- (-) CPU 密集型任务慢 10-30%，Python 数据生态损失，迁移约 2500 行
- 缓解：sync.Pool + gonum BLAS 弥补性能
