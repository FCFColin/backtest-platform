## 1. 入侵检测机制

### 1.1 异常登录检测

| 检测项         | 阈值                     | 处置             |
| -------------- | ------------------------ | ---------------- |
| 登录失败次数   | 5 次/15 分钟             | 账户锁定 15 分钟 |
| IP 登录失败    | 10 次/小时               | IP 封锁 1 小时   |
| 异地登录       | 地理位置突变 > 500km     | 触发安全告警     |
| 非工作时间登录 | 02:00-06:00 管理员登录   | 触发安全告警     |
| 已知恶意 IP    | Threat Intelligence 匹配 | 自动封锁 + 告警  |

### 1.2 实现组件

| 组件     | 文件                      | 功能                           |
| -------- | ------------------------- | ------------------------------ |
| 登录锁定 | `loginLockout.ts`         | 账户/IP 级别登录失败锁定       |
| 登录审计 | `loginAudit.ts`           | 登录事件记录 + IP 地理位置分析 |
| 限流     | `rateLimiter.ts` / APISIX | API 请求速率限制               |
| WAF      | APISIX global_rules       | 注入/XSS 攻击模式阻断          |

## 2. 入侵防范措施

### 2.1 网络层

| 措施         | 实现                               | 状态       |
| ------------ | ---------------------------------- | ---------- |
| 端口最小暴露 | 仅 80/443 对外，内网服务 ClusterIP | ✅         |
| DDoS 防护    | 云厂商 DDoS + APISIX 限流          | ✅（生产） |
| WAF          | APISIX waf 插件（P2-01）           | ✅         |
| IDS/IPS      | 云厂商 IDS + 审计日志异常检测      | ✅（生产） |

### 2.2 应用层

| 措施         | 实现                                  | 状态 |
| ------------ | ------------------------------------- | ---- |
| 输入验证     | Zod schema 验证所有 API 输入          | ✅   |
| SQL 注入防护 | 参数化查询（pg / pgx），无字符串拼接  | ✅   |
| XSS 防护     | React 自动转义 + CSP 头               | ✅   |
| CSRF 防护    | JWT Bearer（非 Cookie），无 CSRF 风险 | ✅   |
| 密钥泄露检测 | gitleaks CI 扫描                      | ✅   |

### 2.3 主机层

| 措施         | 实现                                       | 状态       |
| ------------ | ------------------------------------------ | ---------- |
| 镜像漏洞扫描 | Trivy CI 扫描（HIGH/CRITICAL）             | ✅         |
| 依赖漏洞扫描 | pnpm audit + govulncheck CI 阻断            | ✅         |
| 最小权限容器 | 非 root 用户运行                           | ✅         |
| 只读文件系统 | K8s securityContext readOnlyRootFilesystem | ✅（生产） |

## 3. 告警与响应

### 3.1 告警规则

| 告警                 | 触发条件                    | 级别 | 通知方式               |
| -------------------- | --------------------------- | ---- | ---------------------- |
| `AuthFailureSpike`   | 登录失败率 > 50%/5 分钟     | P1   | AlertManager → webhook |
| `SuspiciousLogin`    | 异地/非工作时间管理员登录   | P2   | AlertManager → webhook |
| `RateLimitTriggered` | 429 响应率 > 10%/分钟       | P2   | Prometheus 告警        |
| `WAFBlocked`         | WAF 规则触发次数 > 100/分钟 | P1   | APISIX → Prometheus    |

### 3.2 响应流程

详见 `docs/compliance/incident-response.md` 第 2.5 节（DDoS / 恶意流量处置）。
