> **最近更新**: 2026-07-25

---

## 1. 责任共担模式

本平台部署于云厂商（阿里云/腾讯云/AWS）IaaS 基础设施之上。物理安全由云厂商承担，平台团队负责逻辑安全。责任划分如下：

| 安全域           | 云厂商责任                       | 平台团队责任              |
| ---------------- | -------------------------------- | ------------------------- |
| **物理机房**     | 机房选址、门禁、监控、消防、电力 | —                         |
| **物理设备**     | 服务器、网络设备、存储硬件       | —                         |
| **网络基础设施** | VPC、物理网络、DDoS 清洗         | 安全组、NetworkPolicy     |
| **虚拟化层**     | Hypervisor 隔离、宿主机安全      | —                         |
| **操作系统**     | 镜像基础安全                     | 容器镜像硬化              |
| **应用层**       | —                                | 代码安全、输入验证、RBAC  |
| **数据层**       | 磁盘加密（可选）                 | 数据库 TLS、字段加密、RLS |

> **测评说明**: 等保三级物理安全条款（8.1.1）由云厂商数据中心认证覆盖。须索取云厂商等保三级/ISO 27001 认证证书作为测评附件。

---

## 2. 云厂商资质要求

部署前确认云厂商具备以下资质：

| 资质               | 用途           | 验证方式       |
| ------------------ | -------------- | -------------- |
| 等保三级（云服务） | 物理安全合规   | 证书复印件     |
| ISO 27001          | 信息安全管理   | 证书有效期验证 |
| CSA STAR           | 云安全联盟认证 | 证书有效期验证 |
| SOC 2 Type II      | 运维安全审计   | 审计报告       |

## 3. 区域可用性

### 3.1 多可用区部署

- **K8s 集群**: 跨 2+ 可用区部署节点
- **PostgreSQL**: 主库 + 流复制副本跨可用区
- **Redis**: Sentinel 集群跨可用区
- **对象存储**: 跨可用区冗余（云厂商默认）

### 3.2 2025 版等保冗余要求

> 2025 版等保指引对三级系统冗余要求更严格：
>
> - 核心网络设备需实现热冗余
> - 性能需满足高峰期需求（核心设备负载 ≤ 80%）
> - 网络边界必须部署入侵检测/防御设备

| 要求             | 实现                             | 状态 |
| ---------------- | -------------------------------- | ---- |
| 核心设备热冗余   | 云厂商 SLB 双机热备 + K8s 多副本 | ✅   |
| 设备负载 ≤ 80%   | HPA 自动扩缩 + 资源限制          | ✅   |
| 网络边界 IDS/IPS | 云厂商 IDS + APISIX WAF          | ✅   |
