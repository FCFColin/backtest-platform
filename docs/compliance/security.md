# 安全管理（等保三级 8.1.1-8.1.3.4 + 8.1.5.2/5.3/5.5）

> 合并自: security-operations + infrastructure-security + development-security

## 1. 入侵检测与防范

### 异常登录检测

| 检测项               | 阈值         | 处置             |
| -------------------- | ------------ | ---------------- |
| 登录失败             | 5 次/15 分钟 | 账户锁定 15 分钟 |
| IP 登录失败          | 10 次/小时   | IP 封锁 1 小时   |
| 异地登录             | > 500km 突变 | 安全告警         |
| 非工作时间管理员登录 | 02:00-06:00  | 安全告警         |

### 防范措施

| 层级   | 措施                       | 实现                                               |
| ------ | -------------------------- | -------------------------------------------------- |
| 网络层 | 端口最小暴露/WAF/DDoS/IDS  | 仅 80/443 对外，APISIX waf，云厂商 DDoS+IDS        |
| 应用层 | 输入验证/SQL 注入/XSS/CSRF | Zod schema，参数化查询，React 转义+CSP，JWT Bearer |
| 主机层 | 镜像/依赖扫描/最小权限     | Trivy+pnpm audit+govulncheck，非 root 容器         |

### 告警规则

| 告警               | 触发                  | 级别 |
| ------------------ | --------------------- | ---- |
| AuthFailureSpike   | 登录失败率 > 50%/5min | P1   |
| WAFBlocked         | WAF 触发 > 100/min    | P1   |
| RateLimitTriggered | 429 率 > 10%/min      | P2   |

## 2. 网络架构与区域边界

### 端口暴露

| 端口      | 服务       | 暴露              | 安全         |
| --------- | ---------- | ----------------- | ------------ |
| 80/443    | APISIX     | 公网              | TLS+WAF+限流 |
| 5432      | PostgreSQL | 内网              | TLS+RLS      |
| 6379      | Redis      | 内网              | TLS+密码     |
| 5001      | API        | 内网(APISIX 代理) | JWT+RBAC     |
| 5003-5004 | Go 服务    | 内网              | Auth Token   |

### 通信加密: 客户端→APISIX TLS 强制; API→PG/Redis TLS 强制(生产)

### 网络隔离: K8s NetworkPolicy 默认拒绝; pg_hba.conf 限制连接来源

### 多可用区: K8s 跨 2+ AZ; PG 主库+流复制跨 AZ; Redis Sentinel 跨 AZ

## 6. 事件处置流程

| 事件              | 症状                 | 处置                                                  |
| ----------------- | -------------------- | ----------------------------------------------------- |
| PostgreSQL 不可用 | API 503, health=down | pg_isready → 检查连接池 → backup-restore.sh           |
| Redis 不可用      | 认证/限流降级        | redis-cli ping → 等 Sentinel 切换(< 30s) → 内存降级   |
| engine-go 不可用  | 503+Retry-After      | curl health → 检查日志 → docker restart → fail-closed |
| 密钥泄露          | gitleaks/审计异常    | 立即轮换 → 撤销 session → 审查日志 → 安全报告         |
| DDoS              | 请求飙升             | 检查限流 → IP 黑名单 → 云 DDoS 防护                   |

### 响应时间: P0 15min 接报/1h 恢复; P1 30min/4h; P2 2h/24h

### 事后: P0/P1 事件 48h 内提交报告; P0 全员复盘, P1 技术复盘
