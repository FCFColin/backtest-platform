## 1. 数据分级标准

### 1.1 分级定义

| 级别        | 定义                       | 示例                                 | 保护要求                       |
| ----------- | -------------------------- | ------------------------------------ | ------------------------------ |
| **L4 极高** | 泄露导致严重法律/财务损失  | 用户密码哈希、JWT 密钥、API Key      | 加密存储 + 访问审计 + 最小知悉 |
| **L3 高**   | 泄露导致商业损失或隐私违规 | 用户个人信息、组织财务数据、回测策略 | RLS 隔离 + 访问审计 + TLS 传输 |
| **L2 中**   | 泄露导致有限影响           | 回测结果、投资组合配置、分析报告     | RLS 隔离 + TLS 传输            |
| **L1 低**   | 公开或低敏感数据           | 标的行情数据、市场指数、CPI 数据     | 无特殊保护                     |

### 1.2 数据资产清单

| 数据类别          | 级别 | 存储位置                                 | 访问控制           | 保留策略                  |
| ----------------- | ---- | ---------------------------------------- | ------------------ | ------------------------- |
| **用户认证信息**  | L4   | PostgreSQL `users` 表（bcrypt 哈希）     | 仅认证服务写入     | 账户删除后 30 天清除      |
| **JWT 签名密钥**  | L4   | K8s Secret / 环境变量                    | 仅运维部署         | 每 90 天轮换              |
| **API Key**       | L4   | PostgreSQL `api_keys` 表（SHA-256 哈希） | 创建时返回一次     | 用户吊销即删除            |
| **用户个人信息**  | L3   | PostgreSQL `users` / `org_members` 表    | RLS 隔离           | 账户删除后 90 天清除      |
| **组织财务数据**  | L3   | PostgreSQL `billing` 相关表              | RLS + admin 权限   | 保留 5 年（税务合规）     |
| **回测配置/结果** | L2   | PostgreSQL `backtest_runs` 表            | RLS 隔离           | 用户可删除，默认保留 1 年 |
| **审计日志**      | L3   | PostgreSQL `audit_logs` + MinIO WORM     | 仅追加，admin 可读 | 保留 180 天（MinIO）      |
| **市场行情数据**  | L1   | PostgreSQL `prices` / `tickers` 表       | 公开可读           | 无限期保留                |
| **CPI/通胀数据**  | L1   | PostgreSQL `cpi_data` 表                 | 公开可读           | 无限期保留                |

## 2. 数据保护措施

### 2.1 传输安全

| 数据级别 | 传输要求             | 实现                                           |
| -------- | -------------------- | ---------------------------------------------- |
| L4/L3    | 强制 TLS（证书验证） | PostgreSQL `ssl: { rejectUnauthorized: true }` |
| L2       | TLS 推荐             | Docker 内部网络默认不加密                      |
| L1       | 无要求               | —                                              |

### 2.2 存储安全

| 数据级别 | 存储要求              | 实现                                               |
| -------- | --------------------- | -------------------------------------------------- |
| L4       | 加密存储（哈希/加密） | bcrypt（密码）/ SHA-256（API Key）/ Secret（密钥） |
| L3       | 访问控制 + 审计       | RLS + RBAC + 审计日志                              |
| L2       | 访问控制              | RLS + RBAC                                         |
| L1       | 无特殊要求            | 公开可读                                           |

### 2.3 数据销毁

| 场景         | 销毁方式                       | 验证                                 |
| ------------ | ------------------------------ | ------------------------------------ |
| 用户删除账户 | 软删除 30 天 → 硬删除          | `DELETE FROM users WHERE id = $1`    |
| API Key 吊销 | 硬删除哈希记录                 | `DELETE FROM api_keys WHERE id = $1` |
| 审计日志过期 | MinIO Object Lock 到期自动删除 | 保留 180 天后自动清理                |
| 备份数据     | WAL-G `delete retain 7`        | 保留 7 份全量备份                    |

## 3. 数据访问审计

### 3.1 审计范围

所有对 L3 及以上数据的写操作（POST/PUT/PATCH/DELETE）自动记录审计日志：

- 操作人（userId）
- 操作时间（ISO 8601）
- 操作类型（CREATE/UPDATE/DELETE）
- 数据变更（before/after JSON）
- 请求来源（IP + User-Agent）
- HMAC 签名（防篡改）

### 3.2 审计日志存储

- **热存储**: PostgreSQL `audit_logs` 表（最近 30 天，支持快速查询）
- **冷存储**: MinIO WORM 模式（180 天，仅追加不可修改）
- **导出**: `auditExporter.ts` 定期从热存储导出至冷存储

## 4. 数据导出与共享

### 4.1 导出审批

| 数据级别 | 导出审批                    | 限制         |
| -------- | --------------------------- | ------------ |
| L4       | 禁止导出                    | —            |
| L3       | 技术负责人 + 安全负责人审批 | 脱敏后导出   |
| L2       | 组织管理员审批              | 仅本组织数据 |
| L1       | 无限制                      | —            |

### 4.2 外部共享

- L3 及以上数据禁止通过非加密渠道传输
- 外部 API 响应中不返回 L4 数据（密码哈希、API Key 哈希等）
- 第三方集成（如 Stripe）须签署数据处理协议
