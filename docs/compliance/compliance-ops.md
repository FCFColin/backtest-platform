## 第三方供应商管理

| 供应商                   | 服务            | 凭证管理                      |
| ------------------------ | --------------- | ----------------------------- |
| Stripe                   | 支付            | STRIPE_SECRET_KEY(K8s Secret) |

## 安全培训与人员管理

- 年度培训: 安全意识（入职+年度）、开发安全（开发者）、应急响应（运维）
- 入职: 保密协议 + 最小权限账号 + 培训；在岗: 定期权限审查；离职: 即时撤号 + 交接 + 审计保留
