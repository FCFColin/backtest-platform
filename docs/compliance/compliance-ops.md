## 第三方供应商管理

| 供应商        | 服务     | 凭证管理                      |
| ------------- | -------- | ----------------------------- |
| Stripe        | 支付     | STRIPE_SECRET_KEY(K8s Secret) |
| BaoStock      | A 股数据 | 无(免费 API)                  |
| Yahoo Finance | 美股数据 | 无(免费 API)                  |
| Cloudflare    | CDN/DNS  | API Token                     |
| 云厂商        | IaaS     | IAM                           |

准入评估: 安全资质审查 + 数据处理协议 + SLA。年度审查: 漏洞扫描 + 合规复核。数据源降级: BaoStock→Yahoo Finance→缓存(ADR-031)。

## 安全培训与人员管理

- 年度培训: 全员安全意识(入职+年度), 开发安全规范(开发者), 应急响应(运维)
- 入职: 签保密协议 + 最小权限账号 + 安全培训
- 在岗: 定期权限审查 + 培训记录
- 离职: 即时撤销账号 + 交接清单 + 审计日志保留
