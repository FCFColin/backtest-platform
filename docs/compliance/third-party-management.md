## 2. 供应商安全评估

### 2.1 准入评估

新引入第三方服务前须完成：

- [ ] 数据流评估：接触哪些级别的数据？
- [ ] 安全资质审查：SOC2 / ISO 27001 / PCI DSS（如适用）
- [ ] 数据处理协议（DPA）签署
- [ ] API Key / 凭证管理方案确认
- [ ] 退出方案（数据导出 + 凭证回收）

### 2.2 年度审查

每年对所有 L3 数据接触的供应商进行安全复审：

- 安全资质有效期验证
- 数据接触范围审计
- 服务可用性 SLA 达标情况

---

## 4. 数据源降级策略

数据源不可用时按优先级降级（`dataFacade.ts`）：

```
PostgreSQL 缓存 → Go data-fetcher 实时获取 → 多数据源 fallback
```

- 单一数据源故障不影响平台可用性
- 数据源全部不可用时返回明确错误（非静默降级）
