## 1. 密码复杂度要求

| 规则           | 要求                           | 等保条款   |
| -------------- | ------------------------------ | ---------- |
| 最小长度       | 12 位                          | 8.1.4.1 b) |
| 大写字母       | 至少 1 个                      | 8.1.4.1 b) |
| 小写字母       | 至少 1 个                      | 8.1.4.1 b) |
| 数字           | 至少 1 个                      | 8.1.4.1 b) |
| 特殊字符       | 至少 1 个（`!@#$%^&*()-_=+[]{} | ;:,.<>?`） | 8.1.4.1 b) |
| 禁止常见密码   | 不在 Top 10000 弱密码列表中    | 8.1.4.1 b) |
| 禁止用户名包含 | 密码不含用户名/邮箱前缀        | 8.1.4.1 b) |

> 实现：`passwordPolicy.ts`（`validatePasswordStrength()`）

---

## 2. 密码生命周期

| 阶段     | 策略                            | 等保条款   |
| -------- | ------------------------------- | ---------- |
| 初始设置 | 首次登录强制设置密码            | 8.1.4.1 a) |
| 有效期   | 90 天强制更换                   | 8.1.4.1 c) |
| 历史限制 | 不可重用最近 5 次密码           | 8.1.4.1 c) |
| 重置流程 | 邮件令牌（30 分钟有效，一次性） | 8.1.4.1 d) |
| 失败锁定 | 5 次失败锁定 15 分钟            | 8.1.4.1 e) |

---

## 3. 密码存储

| 项目     | 实现                           | 说明                     |
| -------- | ------------------------------ | ------------------------ |
| 哈希算法 | bcrypt（cost=12）              | 自适应哈希，抵抗暴力破解 |
| 盐值     | bcrypt 内置随机盐              | 每次哈希独立盐值         |
| 明文禁止 | 任何日志/响应/数据库不存储明文 | gitleaks 扫描 + 代码审查 |
| 传输     | TLS 加密（HTTPS）              | 密码仅在登录请求中传输   |

---

## 4. 密码重置

### 4.1 用户自助重置

1. 用户提交邮箱 → 生成随机令牌（32 字节，Redis 存储，30 分钟 TTL）
2. 发送重置链接（`https://platform/reset?token=xxx`）
3. 用户设置新密码（验证复杂度 + 历史限制）
4. 令牌一次性使用，重置后所有活跃 session 失效

### 4.2 管理员重置

- 管理员可强制重置用户密码 → 用户下次登录须设置新密码
- 管理员重置触发审计日志 + 用户邮件通知

---

## 5. MFA/TOTP 补充

管理员账户强制启用 MFA（TOTP），详见 `docs/compliance/access-control-policy.md` 第 3.3 节。
