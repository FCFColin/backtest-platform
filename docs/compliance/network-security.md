## 1. 网络架构

### 1.1 网络分区

```
互联网
  │
  ├─ CDN / DDoS 防护（云厂商）
  │
  ├─ APISIX 网关（WAF + 限流 + TLS 终止）
  │     │
  │     ├─ API 服务（Express :5001）
  │     ├─ 前端服务（Nginx :80）
  │     │
  │     └─ 内部网络（ClusterIP）
  │           │
  │           ├─ PostgreSQL（:5432，TLS 强制）
  │           ├─ Redis Sentinel（:6379，TLS）
  │           ├─ engine-go（:5004）
  │           ├─ data-fetcher（:5003）
  │           ├─ Unleash（:4242）
  │           └─ MinIO（:9000）
```

### 1.2 端口暴露策略

| 端口      | 服务       | 暴露范围                 | 安全措施             |
| --------- | ---------- | ------------------------ | -------------------- |
| 80/443    | APISIX     | 公网（经云厂商安全组）   | TLS + WAF + 限流     |
| 5432      | PostgreSQL | 仅内网                   | TLS + RLS + 连接限制 |
| 6379      | Redis      | 仅内网                   | TLS + 密码认证       |
| 5001      | API        | 仅内网（经 APISIX 代理） | JWT + RBAC           |
| 5003-5004 | Go 服务    | 仅内网                   | Auth Token           |
| 9090      | Prometheus | 仅内网                   | —                    |
| 3000      | Grafana    | 仅内网（经 APISIX 代理） | OAuth                |

## 2. 通信加密

### 2.1 TLS 配置

| 通信路径                  | TLS             | 实现                                          |
| ------------------------- | --------------- | --------------------------------------------- |
| 客户端 → APISIX           | ✅ 强制         | Let's Encrypt 证书                            |
| APISIX → 后端服务         | 内网通信        | Docker 网络隔离                               |
| API → PostgreSQL          | ✅ 强制（生产） | `pool.ts` `ssl: { rejectUnauthorized: true }` |
| data-fetcher → PostgreSQL | ✅ 强制（生产） | `store.go` `tls.Config`                       |
| API → Redis               | ✅ 强制（生产） | Redis TLS 配置                                |

### 2.2 TLS 版本限制（P3-01 T5）

- **最低版本**: TLS 1.2（禁用 TLS 1.0/1.1）
- **推荐版本**: TLS 1.3
- **APISIX 配置**: `ssl_protocols TLSv1.2 TLSv1.3;`
- **Nginx 配置**: 同上
- **PostgreSQL**: `ssl_min_protocol_version = 'TLSv1.2'`

## 3. 区域边界安全

### 3.1 边界防护

| 措施      | 实现                                     | 状态       |
| --------- | ---------------------------------------- | ---------- |
| 防火墙    | 云厂商安全组（最小端口暴露）             | ✅         |
| WAF       | APISIX waf 插件（SQL 注入/XSS/路径遍历） | ✅         |
| DDoS 防护 | 云厂商 DDoS 清洗                         | ✅（生产） |
| IDS/IPS   | 云厂商 IDS + 审计日志异常检测            | ✅（生产） |
| 入侵检测  | 异常登录告警 + 限流告警                  | ✅         |

### 3.2 网络隔离

- K8s NetworkPolicy：默认拒绝，按需放行
- Docker Compose：服务间通过服务名通信，不暴露端口到宿主机
- 数据库：`pg_hba.conf` 限制连接来源 IP 范围
