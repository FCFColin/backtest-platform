## 1. 安全培训要求

### 1.1 年度培训计划

> 等保 2025 新规：年度安全培训 ≥ 16 学时

| 培训项目         | 学时   | 频率        | 对象        | 形式     |
| ---------------- | ------ | ----------- | ----------- | -------- |
| 等保合规基础     | 4      | 入职 + 年度 | 全体开发    | 线上课程 |
| 安全编码实践     | 4      | 年度        | 开发团队    | Workshop |
| 应急响应演练     | 4      | 半年        | 运维 + 技术 | 实操演练 |
| 密码学与数据保护 | 2      | 年度        | 开发团队    | 线上课程 |
| 社会工程学防范   | 2      | 年度        | 全体员工    | 线上课程 |
| **合计**         | **16** | —           | —           | —        |

### 1.2 培训记录

每次培训记录：

- 培训日期/时长
- 参训人员签到
- 培训内容/材料
- 考核结果（如有）

> 培训记录须保留 2 年以上，供等保测评审查。

## 2. 人员安全管理

### 2.1 入职安全

| 项目     | 要求                            | 验证      |
| -------- | ------------------------------- | --------- |
| 背景调查 | 关键岗位（运维/安全）须背景调查 | HR 存档   |
| 安全协议 | 签署保密协议 + 安全责任书       | HR 存档   |
| 权限分配 | 按最小权限原则分配初始权限      | RBAC 配置 |
| 安全培训 | 入职 7 天内完成安全基础培训     | 培训记录  |

### 2.2 在岗管理

| 项目     | 要求                   | 频率   |
| -------- | ---------------------- | ------ |
| 权限复审 | 审查活跃权限是否必要   | 每季度 |
| 安全培训 | 年度安全培训 ≥ 16 学时 | 每年   |
| 安全考核 | 安全知识测试           | 每年   |
| 违规处理 | 安全违规记录与处置     | 实时   |

### 2.3 离职安全

| 项目     | 要求                       | 时限         |
| -------- | -------------------------- | ------------ |
| 权限回收 | 回收所有系统访问权限       | 离职当日     |
| 密钥轮换 | 离职人员知悉的密钥全部轮换 | 3 个工作日内 |
| 设备回收 | 回收公司设备/令牌          | 离职当日     |
| 数据清除 | 清除个人设备上的公司数据   | 离职当日     |

## 3. 应急响应团队

> 等保三级要求建立 7×24 小时应急响应机制

### 3.1 值班安排

- 工作时间：技术团队全员可响应
- 非工作时间：值班轮换（每周 1 人 primary + 1 人 backup）
- 联系方式：值班表 + 电话/即时通讯
- 响应时间：P0 事件 15 分钟内接报响应

### 3.2 应急联系人

| 角色       | 职责                  | 联系方式 |
| ---------- | --------------------- | -------- |
| 应急指挥   | 决策启动/终止应急预案 | _填写_   |
| 技术负责人 | 技术方案决策          | _填写_   |
| 运维工程师 | 执行恢复操作          | _填写_   |
| 安全负责人 | 安全评估 + 取证       | _填写_   |
